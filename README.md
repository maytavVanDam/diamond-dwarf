# 💎 Diamond Dwarf

A dwarf pushes his mine cart through an endless, randomly generated gold mine. Diamonds pile up in the cart, but every piece of junk he picks up knocks diamonds out of it. Choose your tunnels at each fork and reach the exit before the cave-in catches you.

**Play:** https://maytavvandam.github.io/diamond-dwarf/

## Controls
- ← → / A D: move
- Space: jump (over rocks and floating junk)
- ↑ ↓: choose a tunnel at a fork
- E: smash junk in front of you with the pickaxe
- M: bigger minimap
- R: restart

## Run locally
It's a single `index.html` with no dependencies. Just double-click it, or serve the folder:

```
python -m http.server 8000
```

then open http://localhost:8000
